# Support

## Getting help

- **Usage questions / bugs:** open a GitHub issue using the templates.
- **"My scripts don't run":** first check the dashboard banner — on
  Chrome 138+, ScriptSentry needs the per-extension **Allow User Scripts**
  toggle in `chrome://extensions` (details page for ScriptSentry). This is
  Chrome's requirement for every userscript manager, not a ScriptSentry bug.
- **A script scored badly and you think the scanner is wrong:** open an
  issue with the script's metadata block and the finding you dispute —
  false positives are bugs to us.
- **Security problems:** see SECURITY.md (private reporting only).

## What to include in a bug report

Browser + version, ScriptSentry version, whether Allow User Scripts is on,
and the metadata block of the script involved (redact private URLs).

## Commercial support

None yet — ScriptSentry is a community open-source project (GPL-3.0).
