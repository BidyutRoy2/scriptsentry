🔍 Pre-install Security Report

Every script is statically scanned before it runs: where it runs, what it can read, where it can send data, whether it's obfuscated — a 0–100 trust score in plain English, not raw source code.

⤺ Diff Guardian + rollback

Updates are the supply-chain attack. ScriptSentry diffs new permissions, domains and libraries before an update is applied, keeps every version, and rolls back in one click.

📥 Switch in minutes

Import your Tampermonkey or Violentmonkey backup — scripts and all — with a compatibility report that flags anything MV3 can't run. Nothing is overwritten silently, ever.
